# Kerti Ceruza

Original monoline lettering drawn for this game, including Hungarian accented letters.
Generated by `tools/draw-pencil-font.py` using FontTools (development utility only).
No external font outlines were traced or embedded. The lettering, font file and generation
script are dedicated to the public domain under CC0-1.0:
https://creativecommons.org/publicdomain/zero/1.0/

The warning sketches in `src/forest-warning.ts` are original SVG pen gestures.
