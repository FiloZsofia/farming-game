# Útelhelyezés és napi ágyásgondozás

- 497 sikeres teszt, 72 tesztfájl; `npm run build` sikeres.
- Elkülönített Chromium/CDP ellenőrzés: alsó eszköz megszakítja az ágyáskijelölést; Mara három tényleges ládasornál áll meg; Mara és csomagja az autó mögött; füves rakodóterület bejárható.
- Valódi napváltásokkal: ültetés előtti öntözés azonnal számít; öntözetlen nap után a növekedés és küldetésszámláló nem nő; új öntözés azonnal számít, másnap nem duplázódik. Böngészős hiba nélkül.
- Cypress bináris nem volt elérhető; a böngészős ellenőrzés elkülönített helyi profilban történt.

## Rakodási hely pontosítása

Mara mindhárom ládaoszlopnál a kerítés déli, külső oldalán áll meg. Valódi rakodási folyamatban mindhárom megállás ellenőrizve, böngészős hiba nélkül. Az autó takarása megmarad. Ismételt 497 teszt és build sikeres.
