# 0.3.0 felületi és átadóhely-javítások

490 teszt, 71 fájl; TypeScript és Vite production build. Verzióemelés nélkül.

Böngészős ellenőrzés elkülönített helyi Chromium-profilban, CDP-vel; Playwright nélkül. A Cypress-bináris a környezetben továbbra sem érhető el.

- Valódi gazszedés után a visszajelzés teljes egészében az eszközsáv fölött látszik; külön mobilméretű ellenőrzés is készült.
- Valódi ágyáslocsolás után a natív függőleges Kertészkedés-jelző látszik bal oldalt, 50 pontos skálával.
- Mara közös boltos menüjében a Vásárlás inaktív. A bevételt valódi, elmentett fuvar-elszámolással ellenőriztük: 1191 → 1266, +75 gold. A kijelzés köztes értéket mutatott, majd pontosan az elmentett egyenlegen állt meg; a jelzés eltűnt.
- Közeli képen ellenőrzött kapucsatalakozás, külön erdei ív és az átadó előtti lomb helyes takarása.
- Útvonal- és roncsgeometria automatizált tesztjei sikeresek. Böngészős kivétel nem jelentkezett a fenti folyamatokban.
