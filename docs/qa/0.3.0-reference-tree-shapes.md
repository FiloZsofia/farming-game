# Nyír, lombos fa és fenyő képi referencia alapján

A felhasználó által csatolt kép stílusreferencia, nem beépített külső asset. A három erdei fafajta saját, procedurálisan rajzolt pixelgrafikát kapott: határozott kontúrok, összefüggő levélcsoportok, sötét lombközök és elkülönülő kéreg. A nyír világos törzsű, kékeszöld koronájú; a lombos fa melegebb zöld/barna; a fenyőnek szabálytalan, sötétebb ágszintjei vannak.

A rajz az eredeti helyek körül, az eddigi hozzávetőleges méretben készül; a játékmeneti ütközés változatlan. A közös véletlenszám-fogyasztás 264/fa a lombosoknál és 0 a fenyőnél, ezért a későbbi fák/dekorációk helye nem tolódik el. A gyümölcsfák külön rajza nem része ennek a módosításnak. A statikus rajzolás megmarad, nincs új képkockánkénti feladat.

Ellenőrzés: 511 teszt / 74 fájl sikeres, TypeScript/Vite build sikeres; elkülönített Chromium/CDP-kép a normál játékból, böngészős kivétel nélkül. A friss `production-woodland-refined-trees.png` mutatja az új megjelenést. Cypress bináris nincs telepítve; a vizuális ellenőrzés CDP-vel történt.
