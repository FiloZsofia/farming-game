# Mara nappali gondozása és éjszakai pihenője

- 511 sikeres teszt, 74 tesztfájl; TypeScript és Vite build sikeres.
- Elkülönített Chromium/CDP, a rendes vezérlővel: aznapi lezárt fuvarból visszaállva is metsz, Sam közelről nézheti, mindkét bokrot felkeresi, beszélgetéskor szünetel.
- Éjszaka nem változik a metszés állapota: Mara a szabad útvonalon a Faiskola ajtajához sétál és eltűnik. Éjszakai betöltéskor már bent marad; az üres kocsi a beállóban látszik.
- Böngészős kivétel nélkül. Az aktív mentést és biztonsági másolatát a memóriás mentésvédelem megőrizte.
